# Notices and External References

SystemAI first release is an original architecture/codebase that uses ideas and optional adapters from a broader open-source ecosystem. The repository intentionally does not vendor the complete external frameworks discussed in the architecture research.

Referenced projects include Microsoft UFO/UFO Galaxy, Cua, Agent-S, Open Interpreter/Codex-style runtimes, Agent Desktop, Open Computer Use, agent-ctrl/Computer Use Protocol, Browser Use/Browser Harness/BrowserCode, Stagehand, Skyvern, OpenHands, OpenAdapt, OmniParser and multiple benchmark/security research projects.

Before bundling any external dependency or model asset into a distributable product, review its exact version, transitive dependencies, code license, model-weight license, notices and security posture. See `docs/research/OPEN_SOURCE_REFERENCE_MATRIX.md` and the master blueprint.
